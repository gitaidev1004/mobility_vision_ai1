N_patch = floor(H / patch) x floor(W / patch)
N_total = N_patch + N_det        (N_det = 100)

예) 입력 512 x 864, 패치 16
  격자  : 32 x 54
  패치  : 1,728
  검출  : 100
  전체 N: 1,828
  N^2   : 3,341,584

패치 크기를 바꿀 때
  patch 32 -> 격자 16x27 = 432,  N = 532,   N^2 = 283,024
  patch 16 -> 격자 32x54 = 1,728, N = 1,828, N^2 = 3,341,584
  patch 8  -> 격자 64x108 = 6,912, N = 7,012, N^2 = 49,168,144

패치를 절반으로 줄이면
  토큰 수는 4배, 어텐션 비용은 16배가 된다

위치 정밀도의 하한
  패치 내부 위치는 선형 투영으로 뭉개지므로
  박스 좌표의 유효 해상도가 대략 patch 픽셀 단위가 된다
